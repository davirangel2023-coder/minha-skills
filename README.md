# Minhas skills

Coleção de quatro skills com seus arquivos de apoio originais:

- human-motion-design
- human-team
- humanblender-camera
- character-sheet-studio

## Usar no Codex

Copie as pastas desejadas para `%USERPROFILE%\.codex\skills\`, preservando as subpastas. Cada skill deve ter seu próprio `SKILL.md` diretamente na pasta.

Consulte os arquivos LEIA-ME.md, COMECE-AQUI.md e SKILL.md de cada pacote para dependências e instruções específicas. A publicação neste repositório não instala as skills automaticamente.
